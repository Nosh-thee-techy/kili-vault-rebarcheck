# RebarCheck sample photos

Drop 3–5 top-down cage photos here for `npm run rebarcheck:demo` and `validate.py`.

## How to photograph the cage

1. Stand directly above the cage so the camera looks straight down. Tilted shots stretch spacings.
2. Lay a blank **A4 sheet flat on the cage** (long side 297 mm). A tape measure works if you pass its length as `referenceLengthMm`.
3. Use even light. Avoid hard shadows across the bars.
4. Fill the frame with the mesh plus the reference object. JPEG or PNG, under 10 MB.
5. Do not rely on the phone GPS in the photo file — WhatsApp strips EXIF. Share a location pin (or use the web page's location button) instead.

These photos are visual evidence for a human reviewer. They are not an engineer's sign-off.
